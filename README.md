# 青云盾加密宝

在浏览器中加密文本和 HTTP(S) 链接；默认仅在本机保存密文，也可明确选择云端模式，将**密文**存入 Cloudflare Workers KV，生成可在其他设备打开的解密链接和二维码。解密密钥不包含在链接或二维码中，须通过另一渠道提供。

## 功能

- **QYS1 分段加密（推荐）**：基于浏览器 Web Crypto 的 AES-256-GCM、HKDF-SHA-256 和随机 256 位密钥；每段 16 KiB，独立 nonce、认证元数据。QYS1 是本项目的版本化密文格式，**不是 AI 自创密码算法**。
- 保留 AES、DES、3DES、Rabbit、RC4 旧格式加解密兼容；旧算法安全性不足，不应用于重要内容。
- 本地模式不发送密文；云端模式仅发送密文、算法和有效期元数据，成功上传后才显示跨设备链接与二维码。
- 本地历史记录展示 ID、算法、有效期及撤销状态；可复制本地密文、删除本地副本，创建者还可凭独立的撤销凭据撤销云端分享。不会持久化明文或解密密钥。
- 有效期可选 1 小时、1 天、7 天（默认）、30 天、180 天；云端管理员可使用**仅部署在服务端的** `ADMIN_TOKEN` 创建不过期内容。

## 开发

需要 Node.js 20.9+；建议使用 22.13+（`npm test` 依赖 Node 的 TypeScript type stripping）。

```bash
npm ci
npm run dev
npm run build
npm test
npm run lint
```

`npm run dev` 只启动 Vite，**不包含云端 API**；本地模式及手动密文解密可用。跨设备模式需要按 [部署指南](DEPLOYMENT.md) 配置 Cloudflare Pages Functions 和 KV。`src/services/apiService.ts` 虽然沿用旧名字，云端模式下才调用 `/api/content`，其余操作使用浏览器本地存储。

## 分享步骤

1. 选择推荐的 QYS1 与“云端（跨设备分享）”，输入内容后加密。
2. 只在上传成功后复制解密链接或生成二维码；另行复制密钥并通过**其他渠道**交给接收者。若网络中断导致上传状态未确认，页面会在内存中保留原密文与密钥，允许在 5 分钟内重试同一次请求；请先备份待确认的 ID、撤销凭据和密钥，勿刷新或重复加密。
3. 对方扫码进入 `/decrypt?id=...`，从 KV 读取密文，输入密钥在自己的浏览器里解密。也可手动提供密文和密钥，不依赖云端。
4. 创建结果另提供**撤销凭据**（不是解密密钥），本机会尝试保存，建议单独备份。创建者可在 `/history` 中撤销云端分享；本地模式不生成跨设备二维码。

## 安全与限制

- 明文仅在输入和解密期间存在于页面内存；应用不会将明文或密钥写入 `localStorage`、KV 或 API 请求。请勿将密钥和链接放在同一消息中。浏览器扩展、被篡改的网页、复制到剪贴板的内容仍可能泄露秘密。
- QYS1 单条明文最多 200 KiB。浏览器本地数据可能被清理，备份需自行保存密文和密钥；历史记录不会恢复密钥。
- 过期和撤销只限制从 KV 继续获取密文，**不能收回已下载、缓存或另存的密文和密钥**；KV 最终一致，撤销跨区域生效可能延迟。上传响应不明时的同凭据重试不是原子事务；严格并发撤销需要 D1/DO。撤销凭据在本地缓存里（云端只保存其哈希），与解密密钥不同；丢失本地缓存后可凭备份的分享 ID 和撤销凭据在历史页手动撤销。旧版分享未生成撤销凭据，不能用此功能撤销。
- 本地副本不会因为云端过期/撤销而自动删除，可以复制密文手动解密；永久云端内容受 KV 命名空间、账户和部署存续影响，不是可靠的永久归档。
- 此版本没有 AI 参与加密，也不向 AI 服务发送文本。分段格式使用标准认证加密，不宣称“干扰因子”能够增加安全性。
- 建议按 [Cloudflare Pages Git 集成指南](https://developers.cloudflare.com/pages/get-started/git-integration/)连接 GitHub 仓库部署完整应用，绑定 `CIPHERTEXT_KV`；单独创建 Worker 的 Git 构建流程不会自动识别本仓库的 Pages Functions。公共云端上传接口仍需部署者配置 WAF/速率限制并监控 KV 配额；不要把 `ADMIN_TOKEN` 放入任何 `VITE_` 变量。
